    Lab guide

    Use this panel while you run the shared workshop demo. You do not need an API key. Do not paste tokens into chat.

    1. Access

    1. Open mcp-lab.apps.andrewriley.info.
    2. Enter the email the facilitator asked you to use.
    3. Click Open lab. This Buttercup page is the chat. The same email reclaims the same session.

    2. Run a search

    1. Click a chip under Try these searches, or type in the box.
    2. Click Search. The pending line says Noodling..., then Searching Splunk... when MCP runs.
    3. A misspelling such as noteables still searches — the model decides, not a keyword list.
    4. Stay on this page for follow-ups. Reload starts a new Galileo session.

    3. Galileo traces and evaluations

    1. Open My traces on this page after a search. Sessions are filtered to {you}-workshop-chat-. Facilitators set GALILEO_TRACES_PANEL=0 to hide the tab.
    2. Ask the facilitator for the shared Galileo login. Open console.multitenant.galileocloud.io.
    3. Open project andreril-splunk-mcp-lab, log stream shared.
    4. Find your session: {you}-workshop-chat-… — {you} is the part of your email before @.
    5. Open the latest trace. Expand supervisor → classifier / worker → llm and tool spans. Tool spans are the Splunk MCP calls.
    6. Open Evaluate / Metrics on the trace. Look for groundedness and tool_selection_quality. Scores can stay queued; the spans are enough for the lab.
    Answers are grounded in live Splunk data via MCP, traced to Splunk Agent Observability (Galileo).
